# NFT Liquidity Position Report

## Описание

Скрипт `nft_liquidity_report.py` предназначен для создания отчета по NFT позициям в пулах ликвидности на сети Base (Layer 2 Ethereum).

Скрипт анализирует:
- **Uniswap V3** liquidity positions (ERC721 NFT)
- **Aerodrome** liquidity positions (ERC721 NFT)
- Другие ERC721 токены в кошельке

## Особенности

- ✅ Использует **Etherscan API v2** (BaseScan для сети Base)
- ✅ Фильтрует активные и закрытые позиции
- ✅ Генерирует детальный отчет с временными метками
- ✅ Сохраняет отчет в текстовый файл
- ✅ Поддержка известных DEX протоколов на Base

## Структура отчета

Отчет включает:
1. **Заголовок** с информацией о кошельке и сети
2. **Суммарную статистику** по всем активным позициям
3. **Детали по каждому протоколу**:

   - Дата получения NFT
   - Номер блока
   - Hash транзакции
   - Статус позиции
4. **Информацию о контрактах** для справки

## BaseScan API

Скрипт использует [BaseScan API](https://docs.basescan.org) - аналог Etherscan для сети Base.

### Основные endpoints:
- `module=account&action=tokennfttx` - получение ERC721 транзакций

### Получение API ключа:
1. Зарегистрируйтесь на https://basescan.org
2. Перейдите в раздел API Keys
3. Создайте новый ключ
4. Замените в скрипте `ETHERSCAN_API_KEY`

## Примечания

- Скрипт автоматически фильтрует закрытые позиции (отправленные NFT)
- Время указывается в локальном часовом поясе системы
- Отчет сохраняется в файл с timestamp: `nft_liquidity_report_YYYYMMDD_HHMMSS.txt`
- Для получения данных требуется активное интернет-соединение

## Возможные проблемы

### "Max retries exceeded"
- Проверьте интернет-соединение
- Убедитесь, что BaseScan API доступен
- Проверьте корректность API ключа

### "No NFT transactions found"
- Убедитесь, что кошелек имеет ERC721 токены
- Проверьте правильность адреса кошелька
- Возможно, все позиции были закрыты
